# C1 v1.0｜他作品へ引き継ぐゲームデザイン原則

2026-10-27／短編UIゲーム実験室・C1『適切にご対応ください。』
対象：企画マスター、各作品専用Chat、必要に応じてWork。
本書は**ゲーム設計上の知見を引き継ぐための文書**であり、他作品の修正を承認するものではない。

## ユーザー評価と分析の前提

C1はユーザーからシリーズ内で特にゲームとしての完成度が高いと評価された。ただし以下の成功要因は、コード・人間レビュー指摘・仮想プレイを材料にした**設計仮説**である。他作品とのA/Bテストや多数の実ユーザー比較によって有効性を実証したわけではない。

## 中核の成功要因

1. **最初から役割と勝利条件が具体的。** プレイヤーは中間管理職、全5営業日の業務担当。上司からの無茶な業務要求、若手の育成、コンプラ認定という日常の職場UIがそのままゲーム盤になる。コンプラ20pt到達を避けながら、進捗23・育成9を目指す。
2. **一つの安全な最適解がない。** リスク回避ばかりでは進捗が遅れ、仕事の丸投げや抱え込みは新人の育成を妨げる。3指標は互いに衝突し、何を優先するかが毎回の判断になる。個々の選択の意味は表示された人物・状況から考える。
3. **選ぶたびに即時で派手な結果。** 6つの業務対応を選ぶと、その場で新しい架空の「○○ハラ」が紹介され、認定の有無・短い理由・点数・効果音が出る。失敗も笑い・驚きの小イベントとして成立し、次へ進める。
4. **1回の行為と長期結果が接続。** 5日×3業務の短い区切りと毎日の部長指令。未達は追加作業による進捗減点につながる。月曜の確認時刻、火曜のAI検証など、前日の行動が後日の処理に響く。ルールが日常の業務として自然に納得できる。
5. **周回差分と攻略学習が両立。** 12人物タイプ、業務上の希望・得意分野、23シナリオ、選択順差分。名前・写真・性別・学歴は得点に直結させず、本人が話した希望など意味のある条件を判定に使う。単なる台詞送りや完全暗記を避ける。
6. **結果画面がゲーム評価と物語の落ちを両立。** 目標の分母、達成／未達、部長の写真・絵文字・「激怒」等の反応、新人の短いコメント、18種の結末。数字による評価だけで終わらず、人物の反応として結果が記憶に残る。
7. **厳しさを無理に緩めない。** 初見の失敗は許容し、周回して改善を探すゲーム性を選択した。ロジック検査で攻略経路の存在を確認しつつ、実際に人が再挑戦したくなるかは人間レビューで評価する。過去の要望、シナリオ矛盾、表示の不整合を細かく直した。

## 他作品への適用提案

| 作品 | 移植すべき核 | 避けること |
| --- | --- | --- |
| F1 スーパー店長代理 | 施策→その日の客・クレーム・売上への反応→翌日の経営判断の循環。翌朝に「昨日の選択が何を起こしたか」を短く返す | コンプラ風の6択を移植すること |
| H1 採用面接ホラー | 質問・資料照合→応募者の反応→仮説更新の循環。終局は面接官や応募者の短い反応で印象付ける | 謎の正解・隠しランクを中盤に開示すること |
| M2 メール送信ミステリー | 添付・BCC・会話ログを調査する**操作そのもの**の手応え。情報が増えるたび判断材料の変化を見せる | 正体や推理の正解を途中でスコア化すること |
| D3 写真並び替え | 配置→未来の変化→原因の理解→やり直し、を短い反復として成立させる | 本来の写真因果パズルを複雑なKPI管理に置き換えること |
| M1 文言交換パズル | 交換確定直後に「何が起きたか」を可視化。成功・失敗を演出として明確に区切る | 一手ごとの物語の長い説明、不要な指標増 |
| P1 紙面編集 | 掲載判断→読者や関係部署の反応→翌日の編集条件の変化 | 実在の社会問題の単純な善悪点数化 |
| B1 採用・シフト | 面接→応募者本人の希望・辞退→翌日以降の配置という因果。最終的な勤務表に判断がどう響いたか返す | 全員同じ一律の好感度・達成点 |
| N1 数字当て | 数字の正確さと空気読みの二軸を人物別の表情・セリフに接続し、正答に限らず反応自体を楽しませる | 数値問題そのものに無関係な理不尽ペナルティ |

## 新作レビュー用チェックリスト

- プレイヤーの役割・目標・敗北条件を、初回1画面で理解できるか。
- 中核の**自分で行う操作**があり、ただ読む・選択肢を連続タップするだけになっていないか。
- 1操作に対して、説明しすぎずに**すぐ理解できる反応**があるか。
- 少なくとも一部の行動が後日の条件にも影響し、単発イベントの寄せ集めになっていないか。
- 失敗した結果に納得感があり、「次はこうしよう」という仮説を持って周回できるか。
- 画像・顔・言葉・数値が別々ではなく、一つの結末表現としてまとまっているか。
- 登場人物・乱数差分は論理的整合性を保ち、意味のないばらつきになっていないか。
- AIロジックテスト／実ブラウザ試験／人間プレイを混同せず別々に報告したか。

**最重要：C1と同じ指標数・6択・難易度を他作品へ強制しない。** 各作品固有の中核操作と世界観に「操作→即時反応→累積影響→印象的な結末」の循環だけを応用する。
