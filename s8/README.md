https://tora3-mystery.github.io/short-ui-games/s8/

### 現在実装済み
- 1年次前期・後期の2学期、文学系／経済・経営系／理工系
- 必修の自動配置、選択科目（各学期14科目＋学部固有2科目）
- 週2セット、連続2コマ、土曜日、前提科目、科目抽選
- サークル／アルバイト／学業専念の排他的な選択
- 14単位上限と履修確定10単位下限
- 取得率・抽選・難易度・負荷・課外活動による得点のトレードオフ
- グリッド上で連鎖する成績発表、コンボ、パーフェクトボーナス
- シードで再現できる授業時限と成績抽選、端末内オートセーブ、学部別自己ベスト

### ルール（試作）
- 科目の時間は確定済み。科目をタップすると全コマが一度にプレビューされ、詳細から登録・解除できます。
- 科目は丸ごと履修し、必要コマの一部だけ配置することはできません。
- 必修は自動登録。取得できなかった必修は次の学期に再履修候補として出現します。
- 最大14単位、確定には10単位以上必要です。
- 単位取得率は難度、履修単位数、課外活動で変化します。抽選科目は当選しない場合、受講自体ができません。
- 合格時に得点とコンボ倍率が上昇。落単でコンボが切れます。抽選落ちはコンボを切りません。
- 土曜科目の取得には追加ポイントがあります。

### 公式資料に基づく要素と架空化したルール
- 関西大学の2026年履修登録ガイドは必修の事前登録、重複エラー、登録確定、定員制科目の抽選を案内しています。
  https://www.kansai-u.ac.jp/kancan/course/registration.html
- 武蔵野大学の履修要覧では週2回／2時限連続の授業形態、土曜／集中授業を説明しています。ただし同大学は4学期制を採用しています。
  https://risyuyouran.musashino-u.ac.jp/?p=327
- 本作は架空大学を舞台とし、**年2学期・1〜5限・単位上限14・下限10・成績取得確率・得点・シード乱数はゲーム独自の仕様**です。特定大学の制度をそのまま再現していません。
