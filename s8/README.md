## v0.5.3｜4年間の必修取得・卒業判定の確定（2026-10-29）
- **4年次末の卒業条件**：累計72単位以上かつ未取得必修が0科目。両方満たすと卒業、必修が一つでも残る／取得単位不足なら **GAME OVER**。自己ベスト更新が卒業失敗の表示を上書きしない。
- **4年次の配置保証**：再履修を優先し、新規必修を後ろの時限に移す。どうしても空きが足りない場合は課外活動時間も組み替える。従来の「翌年度へ繰り越す」は4年次には行わない。物理的に配置不能なら明示的な卒業要件未達。
- **4年前期の救済**：4年前期に落とした必修は、通常の1年後を待たずに4年後期の特別再履修に自動配置。4年後期にその授業を落とした場合は卒業失敗。
- **表示整合**：4年後期のリザルトも取得単位数だけでなく未取得必修数を見てCLEAR／GAME OVERを判定。スタート画面とエンディングに卒業条件を明記。
- **AI検証**：300回の自動ロジックプレイで4年後期完走54・卒業成功6・必修未取得44・単位不足4。必修移動342件、4年後期の救済再履修57件、授業重複・活動重複・配置繰越・実行エラーは各0。さらに15条件の救済／未取得GAME OVER／卒業成功の個別テスト全件成功。極端に全30コマを埋める異常テストでは、配置不能を表示してGAME OVER。
- **未検証**：スマホ実画面・保存データ移行・人間プレイ。現在のモデルでの卒業率は極めて低いので、今後のバランス調整候補。

## v0.5.2｜再履修の連鎖・キャンパス移動・過密履修（2026-10-29）
- **必修の再履修**：落単した必修は次年度の同じ学期・同じ曜日／時限に自動で再配置。登録解除はできない。再び落とすと翌年度も同じ位置に残り、選択の自由度が減る。
- **新しい必修との衝突**：前年からの再履修を優先し、新しい必修は原則同じ曜日の後の時限に自動でずらす。複数コマの場合は連続性を維持した移動を優先する。同じ日に入れない場合は後の曜日を探す。全く空きがない例外に限り履修を繰り越す。
- **キャンパス**：3年次以降、学部専門科目やゼミの一部が「専門キャンパス」になる。中央キャンパスとの切替時は原則1コマを移動時間として確保し、時間割上に「↔ 移動時間」を表示。同じキャンパスの連続授業には移動時間不要。5限の後は時間割外なので追加しない。
- **落単リスク**：連続授業は前後の授業の両方を減点（隣接1コマにつき−8pp）。同じ日の週3・4コマ密度にも減点。週の総占有コマ・登録単位による非線形ペナルティも強化。20単位以上の大量登録では期待取得単位が落ちるよう調整。
- **学期確定**：10単位未満でも成績発表へ進める。再履修などで自由なコマが減っても操作不能にならない。進級に必要な累計単位の条件は維持。
- **検証**：750条件ずつの期待単位比較では、登録10/14/20/約30単位で期待取得7.50/8.79/7.20/1.69単位。150自動周回（モック画面）で必修時限変更151件・再履修257件・移動41コマ・表示上の移動重複0・例外0。4年末まで到達23/150で難易度は高い。実ブラウザと人間レビューは未実施。

## v0.5.0 更新（2026-10-29）
- **操作と初見説明**：チュートリアルではコンボ・連鎖を押し出さず、学年ごとに単位条件を達成することを説明。シードは「同じ文字列・学部・活動で時間割再現、同じ選択操作なら成績再現」を明記。空欄でOK。
- **スマホ**：開始・再開・学期切替でスクロール位置を先頭へ復帰させる。画面ラベルは「○年生 前期／後期」に変更。
- **凡例**：必修は★、青。選択は緑、通年は金、課外活動は紫。表示色と凡例を対応。
- **講義一覧**：名前検索を非表示にし、登録可否・取得見込高／低・曜日時限・取得単位・難度でソート可能に変更。「高得点」を「難しい科目」に改名。
- **履修上限撤廃**：科目・活動と重複しない限り14単位を超えて登録できる（v0.5.2で最低10単位要件も撤廃）。
- **過密ペナルティ**：これまでの緩い直線的な減点に、週13コマ超から累乗ペナルティを加え、学期中の登録を増やすと全科目の取得率が下がる。取得率の下限は5%。
- **点数の透明化**：基本点=取得単位×100pt、連続取得ごとに+50pt（最大+250pt）。科目ごとに計算内訳を表示。PERFECT/課外活動の学期ボーナスを別表示。通年前期の中間判定は0pt・0単位。
- **学生生活の負荷増**：活動者は2年次から週+1コマ、3～4年次は週+2コマ。シードに基づく再現可能な配置で、必修・通年の拘束と重複しないようにする。
- **4年後期のランダムイベント**：シードで45%の確率で卒業旅行の予定が発生し、当期の全講義の単位取得率を18ポイント下げる。成績発表前にイベント演出。
- **ロジック監査**：3学部×5活動×20シード=300自動プレイ。8学期まで151件、途中で進級失敗149件。登録単位不足、必修と活動の時限衝突、実行例外は各0件。実ブラウザQAは未実施。

## v0.4.0 更新（2026-10-29）

- **シード**：普段は空欄で構わない。同じ文字列・同じ操作順で授業や成績の乱数を再現可能。履修順を変えると結果が変化する場合がある。
- **学生生活の難易度**：学部×活動で「どんな学生生活か」と総合難易度（目安）を導入。
- **活動時限**：毎学期シードで決定し、コマ数は固定。学業専念0、文化系サークル2、塾講師3（連続2＋単発1）、体育会系3、サークル＋バイト5。必修や通年継続の時限を避けて配置する。
- **単位取得見込**：科目難易度に加えて1限（-9pp）、土曜（-12pp）、連続する授業の先頭（-5pp）、多く埋まった時間割（7コマ超から-1.6pp/コマ）、12単位超の負荷（-1pp/単位）、学年が上がることによるサボり（毎年-4pp）、活動を反映。0〜100%の単純な線形モデルではなく25〜98%に丸める。土曜の科目は引き続き登録できる。
- **得点の単純化**：履修する科目の種類や難易度によるスコア差を廃止。取得時は1単位あたり100pt、連続取得で1科目につき+50pt×（コンボ数-1、最大+250pt）。学期と活動の少額ボーナス、卒業ボーナスは残す。
- **学年ごとの進級条件**：1年末累計16単位、2年末34、3年末54、4年末72。1〜3年末で基準に達しない場合は留年となりその周回が終了する。卒業は累計72単位以上に加えて必修未取得ゼロ。
- **4年前期**：就職活動の説明会や面接が突然集中。履修科目のうち最大3科目が強制的に落単し、成績発表前に演出する。
- **QA**：3学部×5活動×15シード＝225周回の自動選択ロジックテストで進行例外ゼロ。101周回が8学期まで到達し、124周回が途中の進級条件で終了。登録単位不足ゼロ、必修／活動重複ゼロ。これは実ブラウザ操作テストではない。

## v0.3.0 の追加（v0.1.2 → v0.3.0）

1. **空きマス選択**：空き時間をタップすると、そのコマを含む講義を一覧表示。週2セット・連続授業の全占有マスは講義詳細で確認できる。
2. **通年授業**：前期登録すると後期も同じコマが自動的に固定。前期は中間評価のみ（単位ゼロ）。後期末の最終判定で4単位取得。前期の出来が後期の取得率に影響する。いったん登録すると後期は解除できない。
3. **講義拡充**：共通追加科目24、学部ごとの通年科目とゼミ・卒業研究を追加。高学年の専門系授業は3・4年で開放。
4. **全8学期**：1年前期〜4年後期。必修は自動登録、未取得必修は後の学期に再履修候補として現れる。達成条件は72単位以上かつ未取得必修ゼロ。
5. **課外活動による難易度**：学業専念／音楽サークル／塾講師バイト／体育会系／サークル＋バイトの5種類。放課後の占有時間と単位取得率・学期ボーナスのトレードオフ。
6. **成績の見える化**：成績発表に必修と通年科目の結果を表示。次学期の登録画面に前学期の必修結果、結果画面に8学期の必修・通年履歴を掲載。
7. **音の演出**：Web Audio APIの合成効果音（登録・単位GET・落単・コンボ・パーフェクト・最終成績）。ヘッダーの♪でミュート切替。端末に設定保存。
8. **操作補助**：講義名検索、学部別かつ活動別の自己ベスト、途中再開、シード再現。

## 基本ルール

- 1学期につき登録できるのは **最大14単位**、成績発表へ進むには **10単位以上**の登録が必要。
- 科目ごとに固定された曜日・時限へ一括配置し、重複した科目は登録不可。複数コマ科目はセット。
- 必修は自動登録。通年科目の後期は自動継続（4単位分の負荷が後期にも計上）。
- 通年の前期クリアは単位ではなく少量のスコアを獲得。後期判定に成功すると4単位と通常の得点。
- 落単でコンボが切れる。抽選落ちはコンボを切らない。PERFECT SEMESTERで追加点。
- 8学期終了時、取得72単位以上かつ未取得必修なしで卒業扱い、+3000pt。
- 授業時間、評価、卒業条件は架空大学の独自制度。実在大学の履修要覧を直接再現したものではない。
