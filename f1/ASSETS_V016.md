# F1 v0.16 画像素材と表示対応

制作方法：組み込みの imagegen で、既存 `store-normal.jpg` を店舗レイアウトの参照画像として各場面を個別生成した。共通プロンプトは「架空の同一店舗まるまるスーパー、日本の一般的なスーパー、オリーブ色の柱、暖色寄りの蛍光灯、淡いベージュの床、緑の買物かご、白いレジ、生活感のある写実的な16:9写真、スマートフォンでも主題が分かる構図、読めるブランド名や透かしなし」。以下の各場面を追加指定した。

出力は元のPNGを残して制作管理し、公開用には 1100×619px、WebP quality 82 に変換。新規16枚の合計は約2.0MB。既存画像は上書きしていない。

| 新規画像 | 個別の生成指示とゲーム内の用途 |
|---|---|
| `scene-checkout-normal.webp` | 通常のレジ3列と短い待ち列。初日、レジ運営の通常状態。 |
| `scene-checkout-added.webp` | 同じレジを増設し列が短くなった場面。有人レジ増設、セルフレジ導入、レジ系派生施策。 |
| `scene-checkout-overflow.webp` | 待ち列が売場通路にあふれる場面。レジ待ち苦情が深刻な時と施策の副作用。 |
| `scene-aisle-cleared.webp` | カートを整理し通路が通りやすくなった売場。通路整理と通路系派生施策。 |
| `scene-stock-empty.webp` | 普段の商品に欠品が目立つ棚。品切れ苦情が深刻な時。 |
| `scene-stock-replenished.webp` | 補充後の商品棚。自動発注、産直契約、週末在庫融通。 |
| `scene-stock-work-crowd.webp` | 補充カートと箱で通路が狭まる場面。臨時追加発注、補充班、配送再編。 |
| `scene-quiet-floor.webp` | 客の少ない静かな売場。放送縮小、スタッフ休憩、騒音系派生施策。 |
| `scene-renovated-floor.webp` | 陳列島と動線を改めた店内。週末向け大型改装。 |
| `scene-complaint-box-close.webp` | レジ裏に移された木製の意見箱の近景。ご意見箱を隠すグレー施策。 |
| `scene-false-stock-sign.webp` | 空きのある棚に入荷札だけが置かれた場面。架空の在庫表示のグレー施策。 |
| `scene-date-label.webp` | 冷蔵食品の期限ラベルを見直すスタッフ。期限表示のグレー施策。 |
| `scene-owner-inspection.webp` | オーナーと店員が売場を視察する場面。発覚時の是正指示と解任。 |
| `scene-shrine-back.webp` | 店舗裏手の搬入口脇の古い社。不穏ルートの参拝後。 |
| `scene-day8-floor.webp` | 閉店後の無人店内。DAY 8の開店処理前。 |
| `scene-day8-strange.webp` | 無人レジから長いレシートだけが床へ続く店内。DAY 8の会計88件表示後。 |

店舗写真は最近完了した施策を優先し、深刻な苦情が続く時は該当売場へ切り替える。施策の副作用で別の苦情が増えた朝は小さな副作用写真を併記する。DAY 7の通常復帰とDAY 8の段階表示は専用画像を使う。
