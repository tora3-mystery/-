# F1 クレーム・施策データベース｜レビュー用一覧 v0.20.6

**元データ：** `COMPLAINT_POLICY_DB_V020.json`　／　**ゲーム本体：** `index.html`

このファイルはゲーム設計の検証用。隠し条件や施策の内部IDは**ゲーム画面には表示しない**。施策の経済効果・出現日・調査対応を見直す際の正本はJSONと本体コードである。

## 1. 発見ルールの改訂

- **1つの下線：原則1〜2施策。最大2施策。**
- **1件のクレーム全体：複数の下線を調べても最大3施策。**
- 発見時の追加抽選（カテゴリに関連する「おまけ」の施策）は廃止。周回差はクレームの文面・出現順・日付から生む。
- 同じ施策を別の文章から発見しても重複追加しない。発見済み施策や解禁前施策がある場合は、新規発見が0件になることがある。
- 新たな施策を1日最大3箇所まで調査する制限は維持。重要な特殊手掛かりの到達性も維持。
- **通常クレームから46施策**へ対応付け。**特殊条件による4施策**（`audit`、`camera0`、`open0`、`removeShrine`）は従来どおり段階進行等で開放する。

| プレイヤーが調べる文面 | 調査結果 |
|---|---|
| レジに20分並びました | 有人レジを増設／予約受取窓口を設置（2施策） |
| レジが長蛇の列 | 応援スタッフを手配／混雑時間だけレジ応援を固定配置（2施策） |
| レジに20分並び、カートも通れなかった | 下線2箇所を合計して最大3施策 |
| 商店街の神社で商売繁盛を祈願したらどうですか | 街の神社にお賽銭を入れる（1施策） |
