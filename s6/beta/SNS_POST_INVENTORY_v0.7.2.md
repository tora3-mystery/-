# S6 β v0.7.2｜96人のSNS投稿台帳

## 目的

新歓を開始した時点（2026年4月6日）で、96人全員について「どのSNSアカウントを持ち、そのアカウントに投稿が存在するか」を管理する。**投稿のないアカウントは「投稿0件」と明示**し、「アカウントなし」と区別する。TINEの連絡先やPhotogramのフォロー・承認と、投稿自体の存在を混同しない。

## 正本と整合

- 個人ID・アカウント・投稿の正本：既存の共有 `s6/game-data.js`（閲覧のみで変更しない）。
- 公開ハンドルとSNS人格：`s6/beta/social-personas.js`。
- 追加した派生DB：`s6/beta/social-post-index.js`。**96人×TINE/Photogram/Zitter**を個人IDで紐付け、全ての実在アカウントに初期件数／台本上の総件数／投稿ID一覧を管理。そもそも持たないSNSの項目は `null`。
- 任意のゲーム内日付での投稿件数を `S6_BETA_POST_ACTIVITY.at(personId,platform,date)` で参照。4月6日より前に公開された実投稿だけが「開始前件数」。以後はその日までに公開された投稿だけを数える。
- SNS投稿本文は既存24件のみを使用。過去投稿の件数や投稿本文を架空に補完しない。

## UI

- Photogramでフォロー済みのアカウントは、**当日の実際の投稿件数（0なら「投稿0件」）**と開始前件数を表示する。投稿を持たない相手も一覧から消えない。
- 承認待ちのアカウントは、フォロー済みの一覧・投稿数には含めず、「承認待ち」とだけ示す。非公開投稿の件数も漏らさない。
- 公開タイムラインの投稿にはその日までに公開された同一アカウントの件数を表示する。ただし**匿名投稿者の人物名・アカウント名・個別件数は公開しない**。
- TINEの連絡先交換は投稿件数とは別で、既存メッセージ表示・プロフィール閲覧条件を維持する。
