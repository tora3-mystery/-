# S6 β v0.8.2｜初対面での自発的な連絡先交換

更新日時：2026-10-31 11:03 JST

## 追加レビューへの対応

新歓では初対面で連絡先を交換するのは自然なため、v0.8.1で設けた「2日以上交流済み」「親密度3以上」「familiar/easygoing」という自発的交換の必須条件を撤廃しました。

- 積極性3以上・親しみやすさ3以上・慎重さ3以下の人物であれば、**初日の最初の輪を離れるときから**相手から連絡先を提案する場合があります。
- 実際に話しかけなくても、見学者への案内として社交的な先輩が申し出ることがあります。
- 確率は性格（積極性・親しみやすさ・慎重さ）、主催側の先輩かどうか、その場で実際に会話したか、以前からの親しさに応じて変わります。1回のプレイ中は安定したシードで判定し、周回すると変化します。
- たとえばP003のE01-Aでの自発的申出は、初対面・無会話でも発生し、本人と話していれば発生確率が高くなります。
- プライベート寄りのSNS姿勢は初対面の申し出確率を下げます。消極的・慎重な人物は自発的に申し出ません。
- 1つの輪につき申し出は最大1人。TINE・Photogramの当日／翌日承認・今週不可、Zitterの公開方針、交換済みの重複防止は変更していません。
- 初対面での申し出文言を「新歓のお知らせも送れるし」「またどこかで話せるといいし」など、その日の関係性に合うものへ変更しました。「この前も話せてうれしかった」といった初日と矛盾するセリフは使いません。
- 自発的交換は輪の2行動を消費せず、親密度も増やしません。

「話しかける／話を聞く」の合計2行動、受動会話とNPCからの声かけ、全員への個別SNS打診、匿名性・手がかり等のv0.8.1仕様は維持します。

- 初日・交流0回・親密度0で社交的な先輩が連絡先を提案すること、保存後も成立することを確認。
- 400シードの比較で、初対面でも確率がゼロでも100%でもなく、1回話した後に提案確率が高くなることを確認。
- 消極的なキャラが50シード連続で自発的に申し出ないことを確認。
- 既存の全44グループ、180回の旧型シミュレーション、80本の5日間模擬プレイ、SNSの公開範囲、週末7選択を継続テスト。
