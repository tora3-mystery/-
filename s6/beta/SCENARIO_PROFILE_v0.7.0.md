# S6 β v0.7.0｜人物照合・ボカロPプロフィール推理

## 位置づけ

正式タイトル『サークルは、星の数ほどありますから。』。プレイヤーは青嶺大学に入学した新入生。匿名ボカロP「余白ラムネ」から公開の「新歓で見つけたら声をかけて」という招待を見て、6つの音楽サークルを巡る。

**核心：人物名簿を照合し、別の人物に紹介され、学部・学年・音楽経験・活動名義・好きな曲から候補を絞る。金曜には6つの合宿先から1つ選ぶ。** 探偵的な証拠提出・全員の特定・犯罪・恋愛イベントの強制は行わない。

真相は P001 西園寺紬（3年、文学部日本文学科、こもれび、主担当：歌とギター、家ではDTMも行う）。性別は旧DBに項目がなく、物語上は「女性（暫定）」とする。画像制作側の人物設定との照合が必要。性別や名前から楽器の習熟を推定しない。

## 96人の音楽技能テーブル

`music-profiles.js` が人物IDごとに、ボーカル／ギター／ベース／ドラム／キーボード／その他／DTM の各4段階（◎主担当、○演奏できる、△少し経験、×ほぼ未経験）を管理。オリジナル制作・コピー演奏は独立したboolで、両方trueも可能。既存共有DBの基本パートと矛盾しないよう、元の主担当◎を維持し、各人物に2つ目以降の能力を設定した。

概要：Vo◎24人、Gt◎21人、Ba◎13人、Dr◎11人、Key◎15人、その他◎5人、DTM◎8人。Vo/Gtの両方が◎/○の人物は12人（従来のVo/Gt表記だけなら1人）。実際の能力の個別設定は固定の人物ID台帳に保存。会話で「音楽経験を聞く」と手帳に表示する。

## 人物紹介ルート

`story-routes.js` の29個の会話ノードは、会場・輪・人物IDで固定管理する。共通質問「余白ラムネの話」で実行され、話しかけただけで勝手に本人の正体が漏れることはない。紹介された相手には、実際の新歓日程と輪配置で会えるかをQAする。正解ルートは複数経路だが、1周で必ず正解できることは要求しない。

### A｜学部・学年
月曜LAMP受付P003神谷杏奈 → 同会場の歌の輪P017斉藤咲 → 水曜こもれびの譜面・撮影の輪P036宮本由芽 → 隣の歌の輪P001西園寺紬。文学部日本文学科3年生、歌とギターの情報を順に得る。

### B｜ボカロ制作と知人
月曜wav. P004有村遥 → 同じ輪のP040深町瑞希（別名義で実際にボカロ制作） → 火曜残響P006久世澪（録音の協力者、残響とこもれび掛け持ち） → 水曜こもれびP011朝倉律 → P001。名前を明かさない約束は守る。月曜のイベントを選べなかったときは木曜wav.からも久世の掛け持ち先を知れるが、過ぎた火曜の会場へは誘導しない。

### C｜音楽嗜好
火曜JAMBOX P005八代沙耶 → 水曜こもれびP011朝倉律 → P001。羊文学好きという条件は複数人物にあり、それだけでは一意とならない。金曜JAMBOXで同じ噂を聞けても過去の水曜へ戻れないため、直接人物を追うのでなくKの傍証とする。

### D｜SNS・別名義と消去法（補助経路）
月曜wav. P043木島玲も別名義でボカロ曲を制作。P040深町の公開制作と別名義、残響の曲と演奏法を比べ、こもれびにも匿名音楽活動者がいる可能性を検討する。D単独で確定する証拠は要求しない。公開SNSには正体の実名を直接書かない。

### ダミーと誤情報
- P040深町は「底なしサイダー」、P043木島は「窓辺シンセ」という別名義の実際のボカロP。ボカロPだから余白ラムネと限らない。
- P025南雲の「P008米沢は元ギターボーカルだった気がする」→同じ輪P008から「ずっとベース、時々コーラス」という訂正。
- P082の「黒縁眼鏡の深町が余白ラムネかも」→同日の別の輪のP040本人が別名義を説明。
- P072の「西園寺は歌だけでは？」→同日の別の輪のP001で歌・ギターの両方を確認。
- 誤情報は人物の推測や記憶違いとして発話し、ゲーム側が確定的な公式情報として断定しない。訂正可能な導線を必ず用意する。

## UIとゲームバランス

- 1日1新歓、各イベント最大**3輪**、各輪2行動。次の輪への移動はプレイヤーの自由選択。
- 「質問する」から既存の個別質問、所属確認、余白ラムネに関する質問、音楽経験の質問を選べる。情報収集は既存の2行動を消費する。
- 96人の人物手帳：顔・名前・所属照合はその場で正誤判定、夜は再試行可能。相手の音楽経験は実際に質問した後だけ表示する。
- 別の「余白ラムネのプロフィール」手帳：学年、学部、担当、好きな音楽、制作方法、所属の6項目を仮記入。**ここでは正誤を表示しない**。聞いた人物・証言の出所を併記する。
- 正しいサークル（こもれび）を選び本人に声をかけた場合だけ、記入した項目の一致数が後日談に表示される。それ以前は解答を漏らさない。
- 新歓のSNS・その他学生の遊び・休む／選ばない選択肢は維持。誤ルートにも普通の新歓体験を用意する。
- 画像・共有データ`s6/game-data.js`・本編`s6/`・ルートINDEXは編集禁止。画像は別作業。

- 29ノードについて人物所属・グループ・日付・別会場への移動不可能性を静的に照合。
- 96人の各7カテゴリ、オリジナル/コピー、紹介先、3輪まで、証言と訂正、保存、旧シナリオからの独立をQAする。

- 人間試遊重点：3輪2行動がちょうどよいか、紹介先が探しやすいか、96人の顔の混同が楽しさにつながるか、正解とダミーを推理できるか、プロフィール表が入力負担にならないか。
