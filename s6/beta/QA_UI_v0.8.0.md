# S6 β v0.8.0｜会話・SNS・人物手帳のUI再構成

更新日時：2026-10-31 09:00 JST

## 人間レビューへの対応

### 1. SNSの顔を無理に照合させない
- Photogram・Zitterの公開投稿を表示した際、顔写真を持つアカウントは「SNSで顔を見た」段階として人物手帳に記録する。
- 会場で見た人物と同じ顔なら既存の手帳カードにSNSの観察履歴が加わる。ただし本名・所属の正誤判定は勝手に済ませない。
- 顔写真のない公開アカウントは、実在の人物IDに結び付けず「SNSで見かけたアカウント」欄へ追加する。
- 非公開投稿・未来の投稿・匿名Zitterアカウントは、公開範囲と時刻に従い表示し、匿名アカウントを自動的に本人と結び付けない。
- SNS画面の「顔を見比べる」は撤去。内部に残る旧互換操作はUIから呼べない。

### 2. 輪で3回まで自由に行動
- 通常画面の操作を「話しかける」「聞き耳を立てる」「輪から離れる」に統一。質問・SNSの個別選択ボタンを廃止。
- 会話相手はその輪の全員から自由選択。話しかける・聞き耳を立てるの合計3回まで。1回目・2回目の交流後も操作画面に戻る。
- 交流後はアクション欄を見失わないようにスクロール位置を配慮。行動回数は「交流n/3回」で表示。
- 語り掛けたときは少なくとも一度別の人が会話に参加。誰が参加するか、いつ自己紹介するかは個性で異なる。
- 同じ輪で聞き耳を重ねても、同じ文章を3回繰り返さない。
- 余白ラムネの証言・制作知識・誤認の手がかりは、専用の「質問する」ではなく自然な「話しかける」で得られる。既存の人づての連鎖、学部・楽器等の証言台帳、誤情報の訂正ルートを維持。

### 3. 離脱時に全員へ連絡先交換を提案
- 「輪から離れる」で独立画面「連絡先を聞きますか？」を表示。0回でも3回でも交流回数とは別にチャレンジ可能。
- 「全員に連絡先を聞く」と「聞かずに輪を離れる」を選べる。一度聞くと、同じ輪で再び聞いて重複承認させることはない。
- 対象はその輪の全員。既存の個々のアカウント・受入ポリシー・性格に応じてTINE（LINE相当）／Photogram（Instagram相当）／Zitter（X相当）のうち応じるもののみ交換する。誰でも必ず3サービスを教えるわけではない。
- TINEとPhotogramの当日／翌日承認／今週は不可の扱いは従来のルールに従う。Zitterは公開プロフィールでのみ承諾。匿名アカウントは勝手に紐づけず、非公開の情報を公開しない。
- 交換は交流回数や好感度を増やす抜け道にしない。SNSで公開される投稿は実際の公開日・可視性に基づく。

## QA

- JavaScript互換の仮DOMテスト **95/95 PASS**。
- 全44グループで、離脱時に輪の人数と同数への交換確認が行われることを検査。
- 新しい実画面と同じ「話しかける／聞き耳／輪から離れる／全員へ連絡先」の操作を用いて80周の5日間模擬プレイを実施（旧型の180周状態遷移テストも保持）。
- 偶然の正解／不正解の7通りの週末選択、顔画像のみ公開されたSNS人物、顔なしアカウント、匿名・非公開アカウント、X相当の交換、全員同時交換の承認処理を確認。
- 実ブラウザ実操作、スマホ画面、GitHub Pages上の実挙動と人間初見プレイは**未検証**。これらを自動テストと混同しない。

## 次の人間レビュー

- 同じ輪で3回行動しやすいか。選択後の位置は自然か。
- 他のメンバーの自発的な発言が場面と会話相手に噛み合うか。
- 離脱時の全員交換が「誰にどのSNSを教えてもらったか」として明快か、次の輪へ迷わず進めるか。
- SNSで見かけただけの相手について、手帳に載ったことと本人確認の違いが分かるか。
- 新しい接触方式でも、6サークルのボカロP当てゲームとして手がかり・ミスリード・周回性が十分か。
