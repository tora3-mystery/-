# S6 β v0.8.1｜「話す／聞く」2行動・自発的な連絡先交換

更新日時：2026-10-31 10:26 JST

## 今回の人間レビュー反映

### 1. 行動は「話しかける」と「話を聞く」
- 1つの輪につき合計 **2回**。2回後は交流ボタンを閉じ、「輪から離れる」はいつでも選べる。
- 能動：「話しかける」→輪の誰かを指名し、会話の当人・場合により隣の人の反応が返る。ボカロPの証言ルートは引き続き自然な会話から取得。
- 受動：「話を聞く」→輪の参加者同士の問いかけと返事をチャット形式で表示。グループごとに用意された質問・回答を用い、1回目と2回目で話題を変える。
- 受動の基本効果は「聞こえた」に留める。親密度は増えず、自分から話しかけたり個別に自己紹介してもらった扱いにはしない。
- 積極性・親しみやすさ・慎重さによっては、参加者が主人公へ話しかける。本人から直接自己紹介があったときのみ個別紹介フラグを更新。
- 旧セーブの「聞き耳」ログは表示互換を維持。旧3回ログでも残り行動はゼロ、表示は2/2で打ち止め。
- 初回説明文・ボタン・行動カウンタも新方式に統一。

### 2. 連絡先の交換は自発型＋プレイヤーからの依頼型
- 輪を離れる際、以前から何日か話し、親しさがある相手が積極的な性格なら、相手から連絡先を申し出る可能性を追加。ひとつの輪で最大1件、シードで安定判定。
- 自発的申し出は **親しさ（familiar/easygoing）・親密度3以上・積極性3以上・親しみやすさ3以上・慎重さ3以下** を満たし、さらにそのグループで許可されるチャネルに限る。
- TINE・Photogramの即時／翌日承認／今週は不可、Zitterの公開範囲と本人紐づけ方針は従来どおり。交換済みと承認待ちの重複登録は防止。
- プレイヤーは申し出を受けていても「全員に連絡先を聞く」か「自分からは聞かずに輪を離れる」かを選べる。連絡先の打診は輪の2行動に含まない。
- 全員に聞いたときの反応を増加：当日交換／翌日確認／今週は交換しない／親しくなるまで待つ／公開SNS優先／個人用は非公開／SNS未使用／既に交換済みなど。口調も性格・親しさ・相手の個別プロファイルで変える。
- 公開していないハンドルや匿名アカウントを勝手に特定しない。連絡先交換だけで親密度を稼げない。

## 人間レビューで見てほしいこと

1. 1つの輪で「話す／聞く」の2回を選ぶテンポはどうか。
2. 輪の人同士の会話が自然に聞こえるか。特に同じサークルの知り合い同士の質問に違和感がないか。
3. 積極的なキャラからの声かけが多すぎたり少なすぎたりしないか。
4. 数日会った相手からの連絡先の申し出が自然に感じられるか。断り方やSNS公開方針との整合性はどうか。
5. 人物手帳、SNSの顔の観察、余白ラムネの手がかり、金曜の選択が引き続き成立するか。
