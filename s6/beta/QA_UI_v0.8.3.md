# S6 β v0.8.3｜能動的な会話の区切り追加と整合性一次監査

更新日時：2026-10-31 11:43 JST

## UI変更

- 「話を聞く」時と同じように、プレイヤーが話しかけた時にも独立した区切りを表示。
- 文面は「あなたは人物01に話しかけた。」の形式。呼称は人物手帳の表示名に従う。
- 相手の台詞と第三者の反応は従来通り。交流回数、好感度、連絡先交換、乱数判定は変更しない。
- 旧セーブ内の `type:'talk'` のログにも描画時に区切りを表示。保存スキーマは変更なし。

## 技術確認

- 修正後の JavaScript 構文チェックを通過。
- JavaScript V8上のNode互換インメモリ実行環境＋模擬DOMで既存101件に新規1件を加えた **102/102件 PASS**。
- 新規テストで、能動的会話の区切りが1回表示され、受動的会話の既存区切りが維持され、2回の行動ログに一致することを検証。
- 実ブラウザ、スマホ、公開GitHub Pages上での表示・実操作確認は未実施。

## シナリオ・キャラクターの一次整合性チェック

- 共通DB：96人、12新歓、44グループ、125グループ参加枠、132の基本台詞、88質問。
- 全44グループについて、発話者・質問対象・参加者・イベントIDの参照を照合。不一致0。
- 96人の個性プロフィールが全員に存在し、不要な人物IDが混ざっていない。不一致0。
- 132の基本会話文は132種類すべて異なる。
- ボカロP探索の紹介ルート29ノード・17本の人物紹介リンクを検査。紹介元・紹介先はいずれも該当グループに存在し、過去の日付の新歓へ誘導するリンクは0。

- 初対面の発話をグループ参加枠125件で生成すると100種類。重複25組はすべて**同一人物が別の会場に再登場する組合せ**であり、異なる人物の完全一致は0。
- これらは構造と文面重複の検査であり、**会話の意味的自然さ、キャラの語調、シナリオ上の因果、会話バリエーションの満足度を全件精読した監査ではない**。
