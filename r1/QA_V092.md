# R1 α0.9.2｜人間レビューに基づくUIと噂の修正

最終更新：2026-10-29T23:08:30+09:00

## 指摘→修正

1. **ポップアップの見出しが1文字ずつ折り返す**：共通の `.secondary{width:100%}` が閉じるボタンに当たり、flex見出しの幅を押しつぶしていた。ダイアログ見出しを `minmax(0,1fr) 44px` の2列グリッドに変更し、閉じるボタンの幅を44pxに固定。
2. **味・雰囲気の判断材料がない**：来店時に15店舗の味・商品、接客、雰囲気、価格の観察情報を提示。看板・商品進化、客足の変化に沿った差分も追加。評価はプレイヤー自身で決める。
3. **返信しないを真ん中へ**：「根拠を伝える／何もしない／軽く言い返す」の並びに変更。店主の返信がある場合、どれかを選ぶまで「翌月へ」を表示しない。返信のない場合は次へ進める。
4. **呪われた土地（2番地）の匂わせ**：通常NPC口コミに2番地の噂を少確率で混ぜ、実際に2番地の閉店・新規出店があると商店街の噂を追加。『呪い』の仕組みは直接解説しない。

## 区別する事項

コードのシミュレーション・模擬DOM・CSSの静的確認は、実ブラウザ・スマホ実機でのレイアウト検証ではない。人間が報告したモーダル崩れの実表示での再発確認は未実施。今回のテストで全種類のエンディングを網羅したわけではない。
