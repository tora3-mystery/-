# R1 α0.9.7候補｜文体・口コミ多様性監査

日時：2026-10-30 10:23:18 JST
作業範囲：`r1/engine.js`、`r1/app.js`、`r1/index.html`、`r1/status.json`、本記録。

## 見つかった問題と対処

1. ★3の店主返信：既存は最初の4店舗だけ異なるテキスト、残る11店舗は共通文型。ラーメンは固有の返答が既にあるので維持し、残り14店舗すべてに店主の個性を反映した2文型を設けた。ジャンルや評価帯そのものの判定は変更なし。
2. NPC口コミ：通常の低・中・高評価が各2文型だけで、周回すると同じ文章が多い。各4文型に拡張。進化方向と同ジャンルを評価する口コミも、肯定・否定は各2→4、中立は1→3文型に拡張。
3. 未返信文言：「店主からの返信はまだありません。」は事後に返信が来るように読めるため「この口コミには、店主からの返信がありません。」へ変更。
4. 保存互換性：α0.9.6のセーブデータをα0.9.7へ移行できるよう `app.js` の移行対象を追加。

## 固定した仕様

- 15店舗、12か月、投稿選択、経営数値、口コミによるステージ変化、NPC投稿確率、店主返信確率、出店・閉店条件、ラーメン店の特殊条件、18種のエンディング判定は変更なし。
- C画風の画像本制作はWork担当。今回画像素材・CSS・他作品・ルートINDEXは変更しない。
