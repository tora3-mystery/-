# R1 α0.5.0｜出張ランチ導線・公開口コミと炎上イベント

更新：2026-10-29 15:52:55 JST

## ユーザーレビューへの対応
1. 導入から「喫茶店と洋菓子店は進化するが、ラーメン屋は変わらない」のメタ説明を削除。店主の性格を直接説明しない。過去の口コミと店主返信を読んで判断する。
2. プレイヤーを毎月商店街に出張で訪れる会社員と設定。毎月『昼休み→口コミ確認→店選択→食事/おやつ→来店後の口コミ→翌月』と進める。店を選ぶまでは星・ジャンルの投稿フォームを表示しない。
3. 4店舗目『カレー食堂こはく』と店主 杉浦 奏を追加。全5ジャンルの肯定・否定進化、店主返信、店舗表示、年末結果に対応。今後も1店舗ずつの増加を検討。
4. 反論件数はラーメン屋だけに表示していたため公開UIから撤去。炎の返信演出は残す。
5. 初期3件×4店舗の『他のお客さまの口コミ＋店主返信』を用意。毎月1件の新しい他者口コミにも店主返信を付け、月次結果・過去口コミ・全体履歴に表示。
6. 炎上は従来、時折SNS文面が表示されるだけだった。今回、ラーメン屋への複数回低評価に対し抽選・3か月クールダウンで発生する独立イベントを追加。スクリーンショット拡散／話題化、店主ストレス・来訪者増・近隣店客足への波及を実装。炎上へのプレイヤーの専用対処選択肢は未実装。
7. 旧3店舗セーブを読み込んだ際、4店舗化してから保存データを検証する処理へ修正。既存レビューを維持する。
