# V1『この村の評価をお願いします。』｜進化・口コミ・画像系統 横断監査（α0.6.25）

2026-10-27 JST｜対象フォルダ：`proposals/village-review/`

## 目的と対象

海の口コミで神社が森の施設へ進化した例を**一般的な因果矛盾の代表例**として捉え、海以外を含む全16施設の進化データとUIを横断監査した。

対象：16施設×3基本観察項目×2進化方向＝**96第2進化**、2方向の組み合わせを持つ**576最終進化**、低／高の観察状態と★1/2/4/5、地域固有の海観察、画像ルート、村全体の指標、今回の地図UI指摘。

### 2. 今月の口コミと進化が逆方向になる

過去の高評価・低評価が蓄積している場合、最新の★評価とは**同じ観察項目に対して正反対の方向**へ直接進化することがあった。同一250村・3,000口コミシナリオで19件再現。

今回の口コミが進化を生む場合、選ばれた進化方向が今回と同じ観察項目なら、最新口コミが支持・否定した状態に合わせるよう変更した。近隣から波及して当該施設が同月進化する場合も同様に処理。別観察項目への進化はそれまでの蓄積を反映させる。

再試験：250村・3,000口コミ、直接対象の進化1,757件中、同じ観察項目へ進化634件、**逆方向0件**。

### 3. DB取得前の画像ルート

進化DBをまだ取得していない場合に使う`ROUTE_BY_STATE`が現行DBとずれていたため、96第2進化から再構成。★1/2/4/5の**384組合せ**でDB取得前後の画像方向が一致。

### 4. 地図UI

- 「今月訪問可」のラベルを背景の緑と重ならない**濃紫**に変更。
- 選択中は別色の紫枠・「✓ 選択中」。それ以外の施設のベージュ／金色系の意味が曖昧な外枠を廃止。
- 最終進化は外枠ではなく施設名下の「★ 最終形態」で判別。
- 「1年目」、地形名タグ「川沿い」などをヘッダーから削除。**地形判定は内部で維持**。
- 訪問可能施設についての説明と地図凡例も紫ラベル基準に修正。

## 残存・仕様上の限界

- 最終進化で異なる2観察項目を掛け合わせる場合、画像は原則として最初の系統の外観を引き継ぐ。名称・説明は576種だが、実際の外観は35ルートの共有画像を使用。異なる2要素の視覚表現までは保証できない。
- 海ルートでも神社・宿などの既存施設絵に潮のオーバーレイを重ねる方式であり、専用の海辺建物絵はない。地図上で自然に見えるかは人間レビュー事項。
- 固有名詞や山／森の背景描写は海以外の観察項目でも発生し得る。各地形で絶対に存在しないと断定できるもの以外は、現状の地理設定との解釈余地を残した。背景5種類の実画面との整合はブラウザ確認が必要。
- 進化方向とシナリオの論理整合は確認したが、すべての「面白さ」「納得感」を自動判定したわけではない。
