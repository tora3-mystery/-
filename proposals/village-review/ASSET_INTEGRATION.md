# V1｜画像納品後の自動接続・受入規約
更新：2026年10月27日 JST｜ゲーム本体 v0.5.4 α

## このファイルの位置付け
V1の画像納品を受けるための実装接続契約。制作する画像の種類・数量・画風の正本は `ART_ASSET_BRIEF.md`、厳密な145点のファイル一覧は `ASSET_TARGETS.json`。本ファイルは追加の画像を要求せず、**WorkとV1ゲーム実装の境界**を明確化する。

## 重要：画像の納品完了を表すファイル
**`proposals/village-review/assets/asset-manifest.json`** を、画像145点と各WebP版の配置・機械検査・目視監査が済んだ**最後に公開**すること。途中段階で公開すると、ゲームが納品済みと判断して存在しない画像へアクセスする。

JSONのトップレベルは以下。追加メタデータは許容する。

```json
{
  "schemaVersion": "1.0",
  "game": "V1",
  "items": [
    {
      "id": "facility:inn:base:0",
      "category": "facilities",
      "png": "assets/facilities/inn/base-0.png",
      "webp": "assets/facilities/inn/base-0.webp",
      "width": 512,
      "height": 512,
      "alpha": true,
      "anchor": "bottom-center",
      "allowedTerrains": null
    }
  ],
  "speakerAliases": {}
}
```

上記 `items` は表示例では1件のみだが、**実納品は `ASSET_TARGETS.json` の全145件とID・パス・画像サイズ・透過設定が一致すること**。特に `id`、`category`、`webp` の文字列はゲーム本体が直接参照する。ゲームは件数だけでなく、**145件の全ID、カテゴリ、PNG/WebP相対パス、縦横ピクセル、透過フラグがゲーム定義から作る期待台帳と完全一致する場合だけ**画像を有効化する。ファイルパスは**ゲームHTMLからの相対パス `assets/...`** であり、リポジトリルートの絶対パスやGitHub blobのURLに変更しないこと。基本的な `speakerAliases` は任意だが、役職名称の別名を載せておくと今後の拡張が容易。

## 納品前の機械的ゲート
1. `ASSET_TARGETS.json` の145レコードと `asset-manifest.json.items` をID順で照合し、欠落・余剰・重複が0件であること。
2. 145点のPNGと145点のWebPが**実際に存在**し、サイズ・透明度・画像のアンカーが仕様と一致すること。
3. 102点の施設画像のうち、全16施設・全35ルート・初期～最終形態を含むこと。
4. 背景5点は1600×1280、地形タイル8点は透過320×320、隠しエンドは仕様どおり512角または1600×900、村民アイコンは256角。
5. 60px程度の縮小画像を一覧化し、施設の初期・第2・最終形態が区別できること。画像サイズが大きすぎる場合はWebP品質を調整する。
6. 海沿い・離島の背景に建物を焼き込まない。海上には桟橋以外の施設を置かない。5:4の20区画に正しく位置合わせできること。
7. 最後にマニフェストをコミットし、GitHub Pages反映後に公開URLで画像HTTP 200を確認すること。

## ゲームの実装（素材未着で動作する）
- `index.html` の `v1Probe()` が起動時に上記マニフェストを**1回だけ問い合わせる**。未着時には既存の絵文字・CSS地形を表示し、個別画像へリクエストしない。
- マニフェストに145件が揃うと、`v1FacilityId`、`v1Art`、`v1OverlayHTML`、`v1EndingVisual`、`v1Quote` が必要な画像だけを読み込む。個別WebPの読み込みに失敗した場合は**同一素材のPNGマスターを再試行**し、PNGも失敗した場合は絵文字表示を残す。
- 施設の進化前→進化後、閉業・改修等のレイヤー、村民アイコン、隠しエンド差分まで接続済み。実画像の大きさ・アンカー・演出時間の微調整は納品後のV1担当工程。
- ゲーム本体の `index.html`、ルートの `index.html`、他ゲームはWork素材担当が変更しない。素材は `proposals/village-review/assets/` 以下に限定。
