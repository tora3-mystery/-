# V1『この村の評価をお願いします。』共通アート仕様書

制作基準: `ART_ASSET_BRIEF.md` v1.1 / `ASSET_TARGETS.json` 145件 / 2026-10-27 JST

## 固定カメラと合成

- 画風: 日本の田舎を表現する、柔らかい hand-painted 2.5D ジオラマ。子ども向けに寄せすぎず、写実写真・真の等角投影・平面図を混在させない。
- 視点: 俯角約30〜35度、ほぼ平行投影。施設の正面入口は画面下方〜右下方向。
- 光源: 画面左上からの柔らかな昼光。影は右下。
- 基調色: ややくすんだ緑、生成り、土色、落ち着いた瓦色。分岐ごとの色差はシルエットを補強する範囲に限定。
- 施設マスター: 512×512px透過PNG。底辺中央の接地基準は `(x=256, y=440)`。施設本体は左右約40px、上約35px、下約40px以上の余白。
- 地形: 背景は1600×1280pxの不透明PNG、タイルは320×320pxの透過PNG。道路・接続線はゲーム側で描くため焼き込まない。
- 状態・局所演出: 512×512px透過PNG。同じ視点・接地方向で施設へ重ねる。
- 隠しエンド: `*-map` は512×512px透過局所スプライト、`*-ending` は1600×900px不透明年末絵。
- 住民: 256×256px透過PNG。特定実在人物に似せず、64px程度で役割が読める簡潔なバストアイコン。

## 量産前の試作で固定した判断

温泉旅館、道の駅、神社の全進化系列を先に制作し、64px縮小で以下を確認した。

- 画角、光源、左右方向が系列間でぶれない。
- 初期形態から最終形態まで屋根・建物量・付属設備のシルエットが明確に増える。
- 神社の `ritual / mystery / sanctuary`、旅館の `gourmet / retreat / heritage`、道の駅の `tourist / community` が小さな表示でも区別できる。
- 生成元の余白差はアルファ境界を基準に再配置し、施設の接地基準 `(256,440)` と占有率を統一した。

## 透過・性能

- 施設、タイル、オーバーレイ、`*-map`、住民は透過を保持する。
- 背景5種と `*-ending` は不透明とする。
- WebPは見た目と透過位置をPNGに合わせ、通常画像の軽量配信用とする。
- 画像内に施設名、ルート名、ロゴ、UI文字、道路、スクリーンショットを描き込まない。

## 受入基準

1. `ASSET_TARGETS.json` の145件について、PNGと同名WebPの両方が存在する。
2. 台帳のパス、寸法、透過要件と実ファイルが一致する。
3. 施設の底辺中央基準と、64px縮小時のシルエット視認性を確認する。
4. PNG/WebPのコンタクトシートで、欠番・異常な余白・透過不良・画風逸脱を目視する。
5. 画像保存、ゲームへの組込み、GitHub Pages反映、実ブラウザ読み込みは別の検証項目として記録する。
