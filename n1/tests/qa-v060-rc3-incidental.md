# N1｜v0.6.0-rc3 小質問・許容範囲・曜日内順序監査

- 実装・検証日：2026-10-28 JST
- **対象：`n1/dialogue-qa-20261027`。公開`main`のv0.5.1は変更していない。**
- 対象ファイル：`n1/index.html`、`n1/scenario-v04.js`、`n1/side-questions-v1.js`、`n1/tests/qa.mjs`。

## シナリオの構成

- 1週間＝月～金×2問＝10問。月曜の買い物と金曜のセール、木曜の商品確認と金曜の相談を**合計4問の物語軸**として維持。
- 他6枠は、**1回のプレイで4～5問を新小質問プール、残る1～2問を旧来の年齢・価格・時間・芸能人・贈答品・施設年代から抽選**。これにより旧20施設の建築年代クイズも消さない。
- 新小質問は12ジャンル×3基本シナリオ＝**36基本パターン**。さらに周回ごとに人数・割合・在庫・距離等の基準値を変化させる。
- 12ジャンル：架空都市の人口規模／社内アンケート割合／参加者数／在庫数／イベント来場予想／街歩き距離／投票数／椅子の準備数／階段段数／フリーマーケット来場者／図書室貸出冊数／業務進捗率。
- 9人の既存人物写真をそのまま利用し、会話の話者は小質問の内容に連動。曜日内の2つの会話は5曜日とも順番を変えられる。
- 同じ曜日内で同一人物が2回登場した際は小質問抽選をやり直す。物語の因果関係はlegacyIndexで保持する。

## ヒント券・UI

- ヒント券ボタン・残数・詳細ヒント表示を撤去。必要な情報は会話・資料・ログに限る。
- 金曜日の成績画面の「金曜日の後日談」に、庄司徹の既存ポートレート（`assets/portraits/shoji.webp`）を表示。
- 15秒チャレンジと通常モードは維持。会話を読むための準備画面を設ける方式も維持。

## 許容範囲の監査と修正

| 質問類型 | 修正・判断 |
|---|---|
| 人を少し若く見積もる | 真壁は実年齢より1～3歳低め、陽菜は1～3歳高め（旧版の過度なお世辞幅を縮小） |
| 買い物自慢 | 実価格の112～140%の見え方を満点帯に変更。実価格ピタリも共通ルールで100点 |
| 送別品の印象 | 原則、実価格の78～92%。ただし職場備品や設備の相談になった場合はその用途に合わせた予算帯へ切替 |
| 妻へのプレゼントの印象 | 実価格の80～95%。家庭の買い足し／設備調達なら十分な予算上乗せ帯へ切替 |
| 施設年・公式価格・割合・在庫・投票数等 | **正しい整数に一致する場合のみ100点**。誤答に空気読み満点を与えない |
| 架空都市の人口推定 | 「人口は約N万人台」という粗い情報を追加し、約±7,000人の概算を受容。丸めた自然な回答が入ることを検査 |
| 来場者概算 | 前回の「約400人」等の丸い基準値も許容されるよう推定帯を調整 |
| 会議の椅子 | 予定人数＋1～5脚を適正範囲に修正し、内部真値も範囲内の値へ統一 |
| 空気読み満点 | **満点帯内は100点・成功。帯外は成功扱いにしない**。ただし実数値そのものの完全一致は従来どおり100点 |

数値の種類によって異なる距離スケール（単位）を持つようスコア計算も修正。架空の人口や会場人数は**実在する自治体・施設の公表データとは明示的に区別**し、あくまでゲーム内の出来事とする。

## 監査で検出した問題と対処

- 旧建築年・芸能人の「正解を先に出していないか」チェックが、別ジャンルの人口・参加者クイズまで年号と誤認して誤検知 → 当該シナリオのみチェックするよう修正。
- 約400人のイベントを400人と答えた場合に失敗になることがあった → 社会通念上の丸めを受容する幅へ修正。
- 会議の椅子が参加予定人数より少ない真値を持っていた → 予備席数と真値を整合させた。
- 一部曜日で同じ人が2回続けて登場 → 再抽選で回避。
