# N1 neutral category reference image prompts

## Shared production style
Product-mockup category references for a browser game; natural high-resolution catalog photography matching the three human-approved prototypes; warm-neutral matte setting and soft off-white seamless background; soft diffused daylight; subtle natural shadow; centered, fully visible single category object in landscape 4:3; recognizable at mobile thumbnail size; opaque background.

## Shared exclusions
No specific brand or recognizable signature design, text, letters, numbers, logos, trademarks, watermarks, extra props, hands, or unnecessary packaging. Each image represents a broad category and is not an official product photograph.

## Production method
Built-in OpenAI image generation used the three approved prototypes as style references. Original generated PNGs were resized to 800x600 with Lanczos and encoded as WebP quality 90.
