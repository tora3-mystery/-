# N1『正確にお答えにならないでください。』

## 現行版

- バージョン：**v0.4.0**
- 更新表示：**2026/10/27 03:58 JST**
- 公開URL：https://tora3-mystery.github.io/short-ui-games/n1/
- GitHub編集範囲：`n1/` のみ。他作品および一覧トップページの `index.html` は変更しない。
- 静的HTML/CSS/JavaScript。外部API、バックエンドなし。

## 遊び方と固定ルール

- 月〜日の日常シーン12問、各設問3変種。登場人物と基本質問は固定、商品・年齢・ヒントは周回で変化。
- 回答は数値自由入力。空気読み評価を0〜100点とし、事実に完全一致したら無条件100点。両方満たすとダブル成功。
- 回答後は即時答え合わせ。ヒント券3枚、会話ログ、最終成績表示。
- Q2→Q9、Q8→Q12の再登場は同一周回の同一商品・同一メーカー通常価格を参照。
- Q9の他店セールは架空の割引シナリオ。Q2のメーカー公式購入価格や他の公式価格クイズとは明確に区別。

## v0.4.0 主な変更

1. **人物9人を独立高解像度化**：真壁先輩、梅田航、新井悠、梨花、相馬さん、藤野さん、庄司徹、圭介、陽菜を各1024×1024 WebPで制作。既存192×192pxの9面アトラスとbase64埋め込みを廃止。
2. **商品8点を独立ファイル化**：公式の商品名・型番・色・容量・グレードを基準に、拡大可能な独自SVG参考イラストを制作。公式写真の転載ではないことを画面上に明記。
3. **商品拡大表示**：商品画像をタップ／クリックするとモーダルで拡大。Esc、背景クリック、閉じるボタンに対応。
4. **モバイルUI改善**：320px幅でも横スクロールなし。人物写真を104px以上で表示し、入力・ヒント・ナビゲーションのタップ領域を確保。
5. **アクセシビリティ改善**：商品・人物の代替テキスト、入力エラーの `aria-invalid` と `role=status`、モーダルのダイアログ属性を追加。
6. **Q7の不整合修正**：カローラ、Alarmo、無印良品の消しゴムに対し、旧候補商品のヒントが誤表示されていた問題を修正。
7. **進捗表示修正**：Q1開始時から12問に対する現在位置を進捗バーへ反映。
