# N1『正確にお答えにならないでください。』

## 現行版
- バージョン：**v0.3.0**
- 更新表示：**2026/10/26 19:57 JST**
- 公開予定・既存URL：https://tora3-mystery.github.io/short-ui-games/n1/
- GitHub編集範囲：`n1/` のみ。他作品および一覧トップページの `index.html` は変更しない。
- 静的HTML/CSS/JavaScript。外部API、バックエンドなし。

## 遊び方

- 月〜日の日常シーン12問、各設問3変種。登場人物と基本質問は固定、商品・年齢・ヒントは周回で変化。
- 回答は数値自由入力。空気読み評価を0〜100点とし、事実に完全一致したら無条件100点。両方満たすとダブル成功。
- 回答後は基本的に即時答え合わせ。ヒント券3枚、会話ログ、最終成績表示。
- Q2→Q9、Q8→Q12の再登場は同一周回の同一商品・同一メーカー通常価格を参照。
- Q9の他店セールは架空の割引シナリオ。Q2のメーカー公式購入価格や他の公式価格クイズとは明確に区別。

## v0.3.0 主な変更

1. **年齢問題の無意味なカード表示を削除**：Q1/Q5/Q11と待ち時間Q4では、絵文字・「数字推理」・「年齢」などの重複した情報カードを表示しない。
2. **導入文を追加**：各設問に短い情景文を設定。Q1は「出勤途中、たまたま真壁先輩とばったり出会った」から始まる。12問すべてに導入文あり。
3. **有名人の生年をゲーム画面から除外**：Q5の通常会話とヒント券の両方で生年月年を明かさない。代わりに昭和末期の活動時期、還暦を越えた世代という情報から推理する。採点は実際の満年齢を使用。
4. **出題ブランドの客観的な暫定選抜**：2026年3月19日発表の「ブランド・ジャパン2026」一般生活者編・総合力TOP50のブランドを優先し、現時点のランダム商品プールはApple、SONY、Nintendo、MUJI、TOYOTAの5ブランドに限定。
5. **高解像度化の前段階**：新採用商品には輪郭が鮮明な独自SVG模式図を追加。ただし現行の人物・一部商品画像は低解像度WebPアトラスのまま。高解像度化には9人の人物と商品画像を個別ファイルで制作・差替える必要あり。
