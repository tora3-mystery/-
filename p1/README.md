## 操作方法

1. 7日間（2026/10/12〜18）、毎朝の編集メモと前日の反響を読む。
2. 異なる記者2名とそれぞれの取材テーマを選ぶ。テーマ重複可。
3. 一般4本・重点2本（条件により連鎖記事1本）の候補から、トップ・準トップ・小記事2枠に記事を指定して発行する。ドラッグ操作は不要。
4. 毎日の変化と社会からの反響を確認し、翌日の取材・掲載判断へ進む。
5. 7日目の発行後、2027年の県の姿と未掲載記事の一部を確認する。

## 収録データ

`story.json`：記事44原型（調査20／通常16／連鎖8）、反響50原型。企画設計v0.7のテキストを基礎とする。

## 因果モデル（試作版）

- 掲載枠の影響：トップ3／準トップ2／小記事1×2。社会的関心は毎日1減衰、最大12。
- 検証済み取材結果を掲載した場合のみ社会的証拠へ追加。重要記事は準トップ以上で証拠化。小記事は同一証拠記事の再掲載2回で証拠化。
- 公的支援：2枠。病院4日目、観光5日目、保護区域6日目に判定。
- 反響は条件付きかつ0〜8件。情報提供は記者が裏取りして初めて記事本文に反映。SNSの言説だけで疑惑を事実と認定しない。
- 取材記事のうち未掲載の1本を翌日に自動持ち越し。持ち越し記事の追加確認済み情報を保持する。
- `localStorage` に自動保存。端末・ブラウザを変えると引き継がれない。ストレージ無効時は保存しない。
