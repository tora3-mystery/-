# P1｜明日の一面を決めてください。（仮）

短編UIゲーム実験室の新聞編集・未来改変シミュレーション試作版。P1担当範囲のみ。

- バージョン：v0.9.3-beta
- 更新：2026-10-27 11:20 JST
- 公開URL：https://tora3-mystery.github.io/short-ui-games/p1/
- コンテンツ：記事44件／反響50件
- 操作：7日間、毎日記者2人＋取材テーマ、新聞のトップ・準トップ・小記事2本の設定
- フィクション：東雲県、東雲日報、N国・因果観察室

## 仕様

- `index.html`：表示・ナビゲーション。版数とJST更新日時を明記。
- `style.css`：スマートフォン前提の組版・UI。
- `game.js`：決定論的な7日間の因果計算、記事表示、反響、ローカル保存。
- `story.json`：44記事と50反響。外部APIなし。

2026-10-27 JST、ローカルのChromium/Playwrightで検証。

- ローカル保存の存在、ブラウザ再読込の持続確認は継続対象。

初見プレイヤーによる所要時間・難易度・文章品質は未監査です。

## v0.9.0-beta のルール改訂

- 4・5・6日目の分野別の早期成否判定を廃止。7日目も通常どおり「取材2組→紙面4枠→発行」を行う。
- 最終号の発行後、7日間で得た社会的関心・掲載された根拠情報・公的予算を用い、病院・観光・自然の成否を一括判定する。
- 民間で成立する方式を先に評価し、最大2枠の公的支援を未達の分野へ社会的関心の高い順に配分。特別な最終日救済は設定しない。
- SNS反応の発生条件を、早期に確定していた旧政策結果への依存から、実際の報道履歴へ置き換えた。
- 通常記事6種類に後半の日付と矛盾しない続報文面を追加。
- 同一の1〜6日目でも7日目の紙面構成が3目標の結果を変える反実仮想を確認（ローカル試験）。
- この更新はp1内のみ。ルートindex.htmlや別作品の変更はなし。
