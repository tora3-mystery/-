# P1 v0.9.3-beta｜独立監査と改善

対象：P1新聞編集・未来改変ゲーム。更新日：2026-10-27 JST。

## 発見・解消した問題

1. **最終日の特殊評価が残っていた**：最終号のトップと準トップの分野だけで「翌年も安定」と見なす文章が存在。7日間全体の因果計算とは整合しないため、最終号特例の安定評価は廃止し、7日分のトップ／準トップ掲載件数（医療・観光・自然・県政財政）を振り返る方式に修正。3目標の結果を確定する関数自体は変更していない。
2. **重要な追加取材が続報に残らない**：再取材した記事で反響に基づく追加情報がある場合、前回までの続報本文を初回調査文に置き換える処理があった。続報内容を維持して、追加調査で確認した情報を併記するように変更。
3. **追加情報の出所を誤記**：「追加調査済み」の文章は、SNS・投書由来ではない既報の手掛かりも「反響を裏取り」と案内していた。反響由来と既報由来で文章を分離し、同じく記事の内容自体に影響させた。
4. **スマートフォンで記事一覧と掲載枠が離れすぎる**：記事一覧6〜7本を読んだあと紙面設定へ進み、比較のため戻りにくい。編集欄へのページ内リンクと記事一覧への戻りリンクを追加し、スタイルとスクロール位置を調整。ドラッグ操作は導入していない。
5. **3日目中間観測の重複表現**：曖昧な「蓄積」の二重表現を修正し、報道への関心と政策決定が別物であることを説明。

## 実施したテスト

- 編集処理をJavaScript評価環境で起動し、**150シード×7日間＝1,050日分**の通し検証を実施。候補記事数は5〜7として検証し、最終号の報道履歴表示と政策一括判定に例外なし。
- 別途、**500シード×7日間＝3,500日分**を、記事取得と掲載順位を変えた戦略で検証。毎回の紙面作成と最終結果描画まで例外なし。
- 500回の結果は、0目標7回、1目標181回、2目標254回、3目標58回。この分布は機械的な仮想方針の出力であり、人間の初見クリア率を意味しない。
- 500回の中で記事44種・反響50種の全種類を観測。
- 途中保存→読み込みのJSON整合を1ケース検証。保存キー `short-ui-games-p1-v090` と `version:9` を保持し、v0.9系の継続セーブ互換性を設計上維持。
- 追加取材記事の例（I01、佐伯×医療）について、初回公開後の再調査で追加本文が残ることを個別確認。
- 版数／記事数／画面文言／ページ内リンクの静的・描画HTML検査。
