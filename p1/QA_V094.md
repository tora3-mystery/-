# P1 v0.9.4-beta｜人間レビュー前・総合監査

監査日：2026-10-27 JST。対象リポジトリ：`tora3-mystery/short-ui-games`。
変更許可範囲：`p1/`のみ。ルートINDEX・他作品は変更禁止。

## 1. 今回の目的と検証手法

過去の逐次修正による再発を避けるため、状態遷移・取材・紙面・因果判定・反響・保存・文言・公開用アセットを独立に監査した。

- **JavaScriptロジック試験**：JSエンジン内で `game.js` を評価。DOMの主要操作と保存をモック化し、記事・反響・最終判定を生成した。
- **画面生成試験**：`morning/newsroom/published/ending` のHTML生成を確認。ただしヘッドレス／実ブラウザのレンダリングは実施していない。
- **データ監査**：記事44件・反響50件のID、出現条件と文章の時系列、記者×テーマ20通り、掲載分野と政策影響の分類、証拠の公開条件を点検。
- **コード静的監査**：新旧のセーブキー・バージョン・参照整合性、JS構文、読み込みデータの一致検査。
- 乱数を使用した仮想プレイヤーは人間の初見プレイを再現したものではなく、記述された分布を人間のクリア率と解釈しない。

## 2. 修正した不具合・整合性問題

| 重要度 | 問題 | 対応 |
|---|---|---|
| 高 | 政策達成判定は周回の県内情勢・裏取りの有無により変動するが、エンディングの説明が固定閾値を参照していた | `requiredAttention(k)` を共通化し、最終判定と失敗理由を同じ条件で評価 |
| 高 | 公的支援を他分野に配分したため失敗したのに、資金・調査不足など異なる理由が表示された | 公費ルートの条件を満たしている場合は、予算配分による失敗を区別して説明 |
| 中 | 周回ごとの医療・観光・自然の初期情勢の違いが画面から判断できない | 初日と4・7日目の編集長メモで県内情勢を説明（内部の数値条件は非表示） |
| 中 | 県政・財政記事をH/T/Eへの波及先で分類したため、記事一覧・一面・最終集計で県政分野が見えなかった | 新聞の紙面分野と社会的影響分野を分けて表示。県政・財政は紙面分野Gに集計 |
| 中 | 前日に未掲載の重点取材記事が翌日届いても新規重点取材と区別できない | 記事候補に持越区分を付け、前日の保留記事だと明記 |
| 中 | 行政連絡が発行翌日に表示されるのに「本日付」と記載され、日付に矛盾 | R21・R24・R27を日付に依存しない自然な表現へ修正 |
| 中 | 昨日の病院記事への反応が、当日病院記事を掲載していない場合にも届く | R36の条件に当該号の医療記事掲載を追加 |
| 中 | 県政・財政記事が一面トップでも、報道後のフィードバックが医療等のジャンルへ誤分類 | 一面の紙面分野を基準に反応を生成し、既報からの影響は累積報道として説明 |
| 高 | GitHub Pagesやブラウザのキャッシュで旧スクリプトと新JSONが混在する危険 | JS/CSS/JSONのURLへv0.9.4クエリを付与、JSON取得はno-store、データのバージョンを検査。不一致なら明示して停止 |

## 3. テスト結果

### 状態遷移・コンテンツ到達性
- 初期版の全面監査：2,200プレイ・**15,400日**。状態遷移・最終新聞・保存チェックにエラーなし。44記事・50反響へ到達。
- ジャンル分類・持越修正後：3,200プレイ・**22,400日**。記者×テーマ20通りの全組み合わせを個別検査、44記事・50反響の全到達確認。紙面分野Gの集計が生じ、トップ＋準トップ全14本と分野別件数の合計が一致。
- 判定理由・反響フィードバック修正後：2,500プレイ・**17,500日**。朝会・記事取得・紙面編集・発行・結果までエラーなし。4種類の初期情勢全てに到達し、44記事・50反響の全到達を再確認。
- テスト同士で同じ経路・同じ問題を一部重複しているため、単純合計を完全な独立試験とみなさない。

### 個別の異常系・整合性
- 紙面選択・入れ替え・取消し：**20,000回**。4枠間の重複掲載・不正な状態・保存内容の乖離なし。
- 県内情勢4パターン、追加取材証拠5パターン、世論水準など：**6,860組**の政策判定条件をチェック。行政支援不足と関心不足による失敗理由の混同なし。
- 初日、朝会、編集画面、発行済み状態の保存・再読込を検証。保存キー `short-ui-games-p1-v090` とstate.version=9を維持し、旧v0.9系との互換性を意図した実装。
- 新旧記事JSONによる起動テスト：同版は正常起動し、旧版は版数不一致エラーとして停止することを確認。
- 内容データの重複IDなし。候補記事は各日6〜7本。7日目まで毎日2名派遣／記事4本掲載を維持。
- 人間プレイ特有の読み方・反応の解釈・所要時間は本試験からは断定できない。

## 4. 残るリスクと人間テストへの引継ぎ

**必須の外部確認：** GitHub Pagesに最新版が配信されたか、実ブラウザで320/390pxのスクロール・記事選択・反響閲覧・リロード・再開が成立するか。本監査ではGitHubコミットとコード確認までであり、公開環境の実表示は確認していない。

**人間にのみ判断してもらう部分：** 取材を選ぶ楽しさ、SNS・投書の質感、1日の情報量、10〜15分の適正時間、7日目の意外性と納得感。現在の既知の致命的なロジック不具合はテスト範囲では未検出だが、無欠陥を保証するものではない。

## 5. 仕様を変更していないこと

7日間すべて通常取材・通常編集。7日目発行後のみ2027年の成否を判定。記者5人×テーマ4分野から毎日異なる2人、記事4枠、一面自動組版、44記事、50反響、旧セーブ形式を維持。ルートINDEX、他作品には一切変更していない。
