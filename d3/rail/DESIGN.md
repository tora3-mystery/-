# CASE 0048 | 到着しない新都心線 — v0.2-PROTOTYPE

更新：2026-10-25 JST / 管理範囲：`d3/rail/` のみ

## ゲームの骨子

- 舞台は2030年の架空国家 N国・因果観察室。新人調査員は敵国が改変した2026年の北湾新都心線開業史を復元する。
- 2026年の候補写真6枚から4枚を採用し、上から下の順に確定する。6P4＝360配置、勝利は1配置のみ。
- 順序変更後に「因果を確定・観測」を押すと、2030年の同一固定画角が巨大ターミナル／小駅／バスターミナル／封鎖駅の4つに変化する。
- UIは `d3/pretest/` の選択・入替・↑↓・拡大・観測操作を踏襲。ただし実装・シナリオ・画像は鉄道専用、既存ファイルへの参照や改変はなし。
- 5〜10分の初回プレイを狙う。ヒントは3段階でプレイヤーが任意に開示する。

## 証拠写真（内部用IDはUIに表示しない）

| 内部ID | 表示管理番号 | 写真の要点 | 採用判定 |
|---|---|---|---|
| A | R-42 | 旧1番線「最終営業」、工事区域柵、閉鎖 | 正・旧線の使用終了 |
| B | R-07 | 連動制御室で N-7→新03 の進路照合OK、旧01閉鎖済 | 正・連動・使用確認 |
| C | R-31 | 新03ホーム＋N-7、無旅客「回送」確認走行 | 正・試走 |
| D | R-16 | 新03ホーム、旅客、営業「新都心」列車 | 正・開業 |
| E | R-58 | 式典での新線展示模型、線路に見える舞台台座 | 偽・実運行ではない |
| F | R-24 | 同型回送車、旧01ホーム＋S-2 | 偽・別線路 |

正しい配置：A→B→C→D（表示番号 R-42 → R-07 → R-31 → R-16）。

**重要：** 写真内に管理番号そのもの以外の時系列ヒントは載せない。Eは「開業した証拠」と誤認させ、FはCの別写真だと誤認させる。内部IDのアルファベットはプレイヤーには表示しない。

## 運転保安の前提

- Aは旧営業1番線の使用終了を表す。閉鎖前に新線の進路を正式使用することはできないという架空の工事条件を設定する。
- Bは単なる分岐器の手動切替ではなく、既存線との境界切替後の**連動装置・信号・転てつ器の検査と機能確認が終了**したことを示す写真。写真1枚だけでは全検査を証明できないが、因果記録1件が工事完了状態を代表するゲーム上の抽象化とする。
- Cは運行開始前の無旅客試走。試走時は別途適切な運転手配、保安・検査手順が完了している設定。
- Dは最初の営業列車の北湾駅到着。A→B→Cの前提を満たさないDは、事故ではなく**安全側の運行抑止**となる。
- 封鎖駅は衝突事故の結果ではなく、旧線閉鎖後に運行の不成立と不適切な開業公表を受けた調査・信用失墜・投資凍結の結果。実在鉄道で必ずこの経済結果になるという主張ではない。
- 法技術的な参考： [鉄道に関する技術上の基準を定める省令](https://laws.e-gov.go.jp/law/413M60000800151) 第54〜57条、第88条／[カナダ運輸省の連動装置・フェイルセーフ原則](https://tc.canada.ca/en/rail-transportation/standards/railway-signal-traffic-control-systems-standards)。架空N国には同等の保安概念があるという演出上の設定。

## 決定論的な因果状態遷移

4枚を左からではなく**上から順に**処理し、下記のイベントを一度だけ実行する。

1. A：`oldClosed = true`。
2. B：その時点で `oldClosed` なら `routeOK = true`。そうでなければ不成立、後からAを置いても遡及しない。
3. C：その時点で `routeOK` なら `testOK = true`。そうでなければ試走見合わせ。
4. D：その時点で `testOK` なら `open = true`、そうでなければ `openingHeld = true`。その時点ですでに旧線が閉鎖済みなら `heldAfterClosure = true`。
5. E・F：新線開業の技術的な因果条件には寄与しない。観測ログには資料が不適合な理由を示す。

結果の優先順位は、開業成立（巨大ターミナル）→旧線閉鎖後の開業抑止（封鎖駅）→旧線閉鎖済みで未開業（バス）→旧線営業存続（小駅）。分類は各配置に1つのみ。

### 2030年の結末

| 結末 | 発生条件 | 駅前の主な差分 |
|---|---|---|
| 巨大ターミナル | `open` 成立（A→B→C→Dのみ） | 高層ビル、鉄道連絡、拡張駅舎、人流 |
| 小駅 | `oldClosed` 不成立 | 古い小駅舎と地域商店街、旧線存続 |
| バス | 旧線閉鎖、開業不成立、閉鎖後の不正開業要求なし | バス屋根、代替輸送車両、旧駅舎 |
| 封鎖駅 | 旧線閉鎖後に未承認の営業列車進入を要求 | フェンス、閉鎖駅舎、工事停止標識 |

## スコープ・変更管理

- 変更できるのは `d3/rail/` のみ。ルート `index.html`、`d3/index.html`、`d3/pretest/`、`f1/`、`m1/`、`m2/` への書込禁止。
- 公開時は必ずGitHubの最新headを取得し、base tree に上記フォルダの差分のみを適用する。ref更新は `expected_sha` で競合防止、強制上書きなし。
- 現段階の画像は**鉄道専用の再構成イラストSVG**。最終版では独立した写真風アート素材へ差し替えることを推奨。実写の安全保安表示そのものを技術再現するものではない。
- 遊園地版の画像/JS/CSSは参照しない。ルートトップへの掲載は企画マスターの担当。
