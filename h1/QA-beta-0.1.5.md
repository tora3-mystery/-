# H1 β0.1.5｜指摘3件の改修と回帰監査

更新：2026-10-27 11:46 JST
対象：H1『面接中は、席を立たないでください。』
前版：β0.1.4／新バージョン：β0.1.5

## 改修内容

1. 結末画面
   - 最終選考評価の小さな「THE END」を、32〜46pxの大型タイトルに変更。
   - 「GOOD END｜選考終了」「BAD END｜誤採用」「HORROR END｜面接官交代」を視覚的に明記。
   - 中間の3幕エンディングの区分ラベルも大型化。既存3幕・評価ランク・結末判定に変更なし。
2. 応募者氏名の周回変化
   - 4プロフィールごとに架空氏名8組（全32組）を用意。seedから決定し、直前の周回と同じ人物名の連続出現を回避。
   - 応募者番号、顔写真、ES、具体的証拠、過去の経験、回答、異形判定は同じスロットで保持する。
   - `people[i].name` と `S.people[i]` の参照を同時に更新して表記を一致させる。
   - 面接室の雰囲気に直書きされていた旧姓を、該当プロフィールの動的姓に置き換えた。
   - 過年度記録の4名（2018〜2023年）は現在の候補者とは別人であるため固定。
   - 320px程度の幅でも長い名前が4人横並びであふれないよう折り返す。
3. 画面遷移時の先頭スクロール
   - `render` の最終ラッパーで、seed・phase・個人面接対象／回答状態・共通ケース／回答状態・逆質問対象／回答状態・結末の幕を識別する画面キーを管理する。
   - 画面が実際に変わった場合だけ `window.scrollTo(0,0)`。iOSのDOM入れ替え後対策として次のアニメーションフレームでも画面キー一致を確認して再実行。
   - 質問選択、照合メモ、資料タブ、応募者の選択など、同じ場面の操作中はスクロールを維持。
   - HTMLの`scroll-behavior:smooth`をこの作品では無効にし、即時スクロールを優先。
   - 以前のリセットで残っていた無効な`file`タブ指定を新周回で`es`へ正規化。

## 検証結果（実ブラウザのE2Eではない）

- 4,000周回相当、16,000個の氏名表示：名前重複なし、連続する周回で同一応募者の氏名が変化、各周回内の固定、シナリオ側人物名との一致を確認。
- GOOD / BAD / HORRORすべてで最終評価の大きなTHE ENDとエンド種別・異形の氏名を検証（計3種）。
- 画面状態の独立シミュレーション：共通質問選択や個人面接の質問選択ではスクロール維持、回答表示・次のケース・個人面接結果・エンディング幕変更では先頭へ戻る制御を確認。
- β版の証拠モデル：144周回相当、強い証拠144件・補助証拠288件を再検査。
- 実際の`h1/index.html`から読み込むJavaScript23本について、各ファイルの構文解析が通過。
- 過年度記録4名と現在の従来4名の氏名は衝突なし。
- GitHub mainの対象ファイルを取得して編集、ルートINDEXは既承認範囲でH1のバージョンと更新日時のみ更新。他作品の表示は保持。
