# H1 α0.6.2｜初見テストプレイ手順

対象：『面接中は、席を立たないでください。』。プレイヤーへのゲーム内ヒントやネタバレを増やさずに、操作と推理を評価するためのチェックシート。

## 初見プレイヤーに渡す説明
「10〜15分程度を想定した短編ブラウザゲームです。画面内の説明だけを頼りに最後までプレイしてください。途中で困ったこと・気づいたことはそのまま記録します。」

## 観察すること
- [ ] 導入で「何を調べるゲームか」が分かる（追加の口頭説明不要）
- [ ] 4人の個人面接で質問を選べ、顔や人物の区別がつく
- [ ] 3回のグループ面接で同じ職場ケースに4名が回答することを理解できる
- [ ] 気になった発言を保存する機能に自分で気づく
- [ ] 発言の照合は任意であることを理解する／資料から矛盾に気づける
- [ ] 逆質問の「非公開記録を明かす」選択の危険性を理解できる
- [ ] 不採用者を選んだ理由を、結末表示**前**に言葉で説明できる
- [ ] GOOD / BAD / HORROR の意味が最後に理解できる
- [ ] スマホ（幅320～390px相当）で質問選択、資料スクロール、人物タブ、照合操作が問題ない
- [ ] 表情差分の同一性・自然さ・画質に違和感がない

## 終了後インタビュー（30秒程度）
1. 誰を不採用にしたか。どの発言・記録が決め手だったか。
2. 気になる発言を保存したか。照合画面を使ったか。なぜか。
3. 最も面白かった操作は何か。退屈になった箇所はどこか。
4. 結末に納得したか。ホラーで「何が起きたか」を理解できたか。
5. もう1周したいか。その理由は何か。

## 最低限の実施計画
- 初見プレイヤー3名程度から開始（PC利用者、スマホ利用者、謎解き好きでない人を含める）
- 正解率と推理の「証拠を挙げられた割合」を分けて記録する
- テスト人数が少ない間は、正解率の数値を母集団の統計推定に利用しない
- 問題の再現に必要なのは、プレイ時刻・ブラウザ/画面幅・選んだ個人質問・共通ケース・不採用者・発生したエンド・スクリーンショット。個人情報は採取しない

## 開発時QA（本版）
新設データ：共通ケース3×6、4人物、3種の借用アンカー。スクリプト上の模擬通し操作は4異形×3エンド。ブラウザ実機の表示・体感時間は実テストで別途確認する。
