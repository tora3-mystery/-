# K1 残存画像7枚・素材QA

- 基準: main `5ebca767bc09544f318a847221f082b9dc1eb683`。K1 α0.12.0 基準 `fd3c04ac36318d9974987b90064326d4d29c04ef` からのmain更新はR1のみ。
- 既存素材35行の台帳はそのまま保持し、7行を追記。既存画像を変更しない。
- 7枚は実在の建物や人物写真を使わずimagegenで制作。基準画像を参照した編集を優先。
- 404は左端扉。3つの荷物の位置関係を夜間と回収画像で維持し、中身は夜勤機材・子どもの工作とした。普通の家族であり、怪異を示さない。
- 405は左から2番目の表札を外し、壁の微細な擦り跡を付けた。スマホ幅では差分が小さいため、必要に応じてゲーム側で局所拡大を用いる。
- quietmailは希少な条件付きイベントのみ。初稿は数字らしき記号と扉全開があり、再生成して無文字・投函口だけの開きに修正した。
- チラシは文字・家賃・部屋番号を入れず、ゲーム側のHTMLで正確に重ねるための空欄を残した。
- GAME OVERの玄関は室内側の新しい視点であり、外廊下側の基準扉と色・取手・壁・床の調子を合わせた。完全な画素位置一致を意図する画像ではない。
- 7枚のWebPデコード、指定寸法、SHA-256、重複なしを機械確認。320/390/428相当の縮小シートで構図と主題を目視確認。ゲーム組込み・実ブラウザ・実機表示は未実施。
- 残存課題: 生成編集による壁テクスチャと床目地の軽微な揺れ。405の表札跡とquietmailの細い投函口は320px全景では発見しにくい。チラシの情報はHTMLで配置する必要がある。
